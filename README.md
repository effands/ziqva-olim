# ZIQVA OLIM

Web responsive untuk melatih anak TK/PAUD sampai SMA/SMK/MA menjawab soal-soal olimpiade sesuai jenjang dan jenis sekolah (Umum/Negeri, Madrasah MI-MTs-MA, Sekolah Kristen, Cambridge).

## Fitur
- 4 jenjang: TK/PAUD, SD/MI, SMP/MTs, SMA/SMK/MA
- 21 mata pelajaran, 200+ soal original lengkap dengan pembahasan: Matematika, Bahasa Inggris, IPA/Sains, Fisika, Kimia, Biologi, Bahasa Indonesia, IPS & Sejarah, PPKn, Informatika, Bahasa Jawa, Bahasa Arab, PAI, Akidah Akhlak, Fikih, Al-Qur'an Hadis, SKI, Agama Kristen, Cambridge English/Science/Maths
- Mode Ujian: timer 1 menit/soal, progres, palet nomor soal, tombol Dengarkan Soal (text-to-speech), dialog konfirmasi kumpul
- Mode Latihan: cek jawaban + pembahasan langsung
- Hasil: skor besar, medali Emas/Perak/Perunggu, review per soal
- Prestasiku: riwayat latihan tersimpan per perangkat, statistik total latihan, rata-rata, skor terbaik
- Login Guru & Orang Tua: pantau skor anak/murid dengan Kode Pantau per peserta (kode tampil di layar hasil & Prestasiku), dashboard peringkat kelas, rata-rata, dan latihan terbaru

## Teknologi
React + TypeScript, server actions, Drizzle ORM (SQLite).
