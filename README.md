# ZIQVA OLIM

Platform latihan olimpiade interaktif untuk semua jenjang, dari TK/PAUD hingga SMA/SMK/MA.

Situs publik: https://effands.github.io/ziqva-olim/

- 20 soal acak per sesi, Level 1-5, Mode Ujian & Mode Latihan
- Perpustakaan Belajar per jenjang x mata pelajaran
- Pantauan skor untuk guru & orang tua dengan Kode Pantau
